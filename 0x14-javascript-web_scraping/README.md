# 0x14. JavaScript - Web Scraping

## Description
This project focuses on HTTP requests, asynchronous JavaScript operations, and reading/writing files using Node.js modules. It covers interacting with external REST APIs (such as SWAPI and JSONPlaceholder), handling API responses, and performing basic web scraping tasks using the `request` module.

## Technologies & Environment
- **OS:** Ubuntu 20.04 LTS
- **Runtime:** Node.js (v14.x)
- **Style Guide:** [JS Semi Standard](https://github.com/standard/semistandard)
- **Primary Modules:** `fs`, `request`

## General Requirements
- Allowed editors: `vi`, `vim`, `emacs`
- All files end with a new line.
- The first line of all scripts is exactly `#!/usr/bin/node`.
- All files are executable (`chmod +x`).
- Code is semistandard compliant (`semicolons` on top, AirBnB style references).
- Use of `var` is strictly prohibited.

## Tasks Overview

| File | Description |
| --- | --- |
| `0-readme.js` | Reads and prints the content of a specified file in UTF-8 format. |
| `1-writeme.js` | Writes a given string to a specified file path in UTF-8. |
| `2-statuscode.js` | Displays the HTTP status code returned from a GET request to a URL. |
| `3-starwars_title.js` | Prints the title of a Star Wars movie based on the episode number using the SWAPI endpoint. |
| `4-starwars_count.js` | Counts and prints the number of Star Wars movies featuring Wedge Antilles (character ID 18). |
| `5-request_store.js` | Fetches the HTML/text body of a URL and stores it inside a specified local file. |
| `6-completed_tasks.js` | Computes and outputs the number of completed tasks per user ID from a target JSON payload. |
| `100-starwars_characters.js` | Prints all character names associated with a Star Wars movie ID. |
| `101-starwars_characters.js` | Prints all character names of a Star Wars movie in the exact order listed in the API payload. |
