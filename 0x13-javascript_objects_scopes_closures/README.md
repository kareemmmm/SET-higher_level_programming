# 0x13. JavaScript - Objects, Scopes and Closures

## Description
This project covers JavaScript Object-Oriented Programming principles including ES6 class syntax, constructors, methods, inheritance, and prototypical chain concepts.

## Requirements
- Node.js version 14.x
- Style guide: `semistandard` (version 16.x.x)
- All `.js` files are executable and end with a new line.
